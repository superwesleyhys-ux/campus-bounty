## 本轮要解决的问题

发布者可以修改已有悬赏和实物商品，包括已有申请、邀请或订单的情况。修改形成新版本，申请人和冻结的团队成员明确确认新版后，发布者才能发出相应的新邀请。已签协议与已有订单继续保留原条款。暂停隐藏公开招募或销售入口，不取消原协议、订单或库存预占义务。

编辑界面提供草稿、取消、过期版本重新核对和未知结果恢复。申请与购买绑定用户实际看到的版本；不能悄悄接受另一个版本。已有历史、通知和授权会话保留上下文。

## 独立技能试用

使用 dogfood 方法，由独立 Astra High 测试者从新建、未登录的可见 Chrome 会话开始，通过页面上的示例身份进入。没有注入会话、读取产品源码或修改原用户记录。

实际浏览器会话为 **22.48 分钟**，保留 61 张截图、操作观察和合成记录清单。连接浏览器没有可用录像接口；没有录像。早期手机截图部分仅含页头，原图保留，并补拍实际恢复的编辑字段。

已完成的有界旅程：

- 发布悬赏、建队并邀请成员、团队申请、发布者修改条款、暂停及恢复发布。
- 两位成员明确确认新版、三方站内讨论、发布者邀请、申请人接受，并从历史重新打开协议。协议显示新版 150 美元条款及“等待资金”，没有表示实际付款。
- 实物商品创建未付款订单；卖家改价后，旧订单仍保留 25 美元。另一买家重新查看当前报价后选择不预订。
- 390 像素宽度下，编辑草稿刷新恢复，键盘取消及放弃修改，返回未改变的商品。
- Workspace 和 Saved 的较旧页面打开详情后，返回链接保留正确的分页游标。

独立试用确认 **1 项 medium 体验问题**：返回较旧列表会丢失阅读位置。Saved 两次从滚动位置 1115 返回到 0；Workspace 旧订单页也观察到返回顶部。该问题进入集中修复。

独立试用未验证旧报价实际提交后的拒绝、暂停后商品或悬赏从另一浏览列表消失、真实支付、外部邮件、运输或生产容量。前两项安排在最终工程复测补证；不能把补证称为原独立试用重新完成。

## 执行决定及后续范围

- 沿用既有完整页面编辑器，容纳多里程碑输入；代价是需要验证编辑、取消与历史返回上下文。
- 所有升级先保留旧数据并建立备份，严格模式由控制器单独切换；没有把迁移观察值伪装为历史同意。
- 当前确认与历史确认分开读取，使用新增索引限制历史查询工作量；完整冻结成员不受分页截断。
- 在源码冻结时并行开展独立 UI 试用与最终代码审查，收齐后再集中修复；代价是试用结束前不热改源码。
- agent-browser 不可用时使用已连接 Chrome 执行试用方法，明确没有运行该二进制，也没有录像。
- 强制撤权、暂停锁和原始业务插入诊断仍不执行；有限的普通并发和源码分析不冒充穷尽并发证明。
- SQLite 警告如实保留，不为美化输出而抑制。

完整产品仍需签约后的延期/范围/奖金变更、私有材料与数字商品、支付退款结算、真实邮件与身份恢复、举报争议及生产部署。以上继续留在全交互清单中，本轮不会把它们划为已完成。
